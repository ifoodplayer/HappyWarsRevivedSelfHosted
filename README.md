# Happy Wars Revived — Self Hosted

**Supported platforms:** Xbox 360 and Windows 10

Download Self-Hosted from [Releases](https://github.com/ifoodplayer/HappyWarsRevivedSelfHosted/releases) before getting started.

### Limitations

- Coop mode on Xbox 360?
- Cross-play between Xbox One & Windows 10

### Installation Guide

<details>
  <summary>Windows 10</summary>
  <br>

  1. Obtain a decrypted UWP dump of Happy Wars
  2. Move `d3d11.dll` & `UWPInstaller.bat` into your game folder
  3. Run `UWPInstaller.bat` in the game folder
  4. Open `HappyWarsRevived.exe` and launch Happy Wars from the Windows Start Menu

</details>

<details>
  <summary>Xbox 360</summary>
  <br>

  1. Open `HappyWarsRevived.exe`, copy `Sunrise2.xex` and `Sunrise2.ini` to your USB/HDD and add the `.xex` to DashLaunch
  2. Find any playable Title Update (other than the shutdown update)
  3. Spoof your Title Update to join Xbox Live without a forced update — follow the [Byrom guide](https://byrom.uk/tuts/xexspoofing/)
  4. Open `HappyWarsRevived.exe` and launch the spoofed Happy Wars version from the XEX

</details>
